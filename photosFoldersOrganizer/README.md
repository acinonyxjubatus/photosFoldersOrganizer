# Photos Folders Organizer

Набор Bash-скриптов для копирования фото и видео с последующей автоматической
сортировкой по папкам месяцев (`YYYY-MM/`) по дате модификации. Файлы
с отсутствующей или невалидной датой помещаются в папку `unknown/`.

## Состав

| Скрипт | Назначение |
|--------|-----------|
| `src/photos_phone_sync.sh` | Копирование с Android-телефона через ADB |
| `src/photos_folders_sync.sh` | Копирование из любой локальной папки (например, внешнего HDD) |
| `src/common.sh` | Общие функции (логирование, прогресс-бар, парсинг, индексация) |
| `tests/test_photos_phone_sync.sh` | Тесты для `photos_phone_sync.sh` |
| `tests/test_photos_folders_sync.sh` | Тесты для `photos_folders_sync.sh` |

## Общие функции

Оба скрипта используют общий набор функций из `common.sh`:

- Прогресс-бар с именем файла, процентом и скопированным объёмом
- Логирование каждой операции в `~/.phone_sync/` (опционально, флаг `-l/--logs`)
- Парсинг метаданных файлов и нормализация дат в `YYYY-MM/`
- Индексация уже существующих файлов для мгновенного пропуска
- Разрешение конфликтов (размер не совпадает): перезаписать / пропустить / пропустить все
- Режим проверки (`--dry-run`) без реального копирования
- Единая функция `sync_files()` — основной цикл синхронизации, параметризуемая колбэками
- Спиннер при длительных операциях (сканирование источника, индексация файлов на ПК)

### Параметризация `sync_files()`

Общая `sync_files()` в `common.sh` скрывает весь основной цикл (сканирование, сортировка,
пропуск существующих, конфликты, прогресс, итоговый отчёт). Каждый скрипт лишь определяет
два колбэка и три текстовые переменные:

| Колбэк / переменная | Назначение | photos_phone_sync.sh | photos_folders_sync.sh |
|----------------------|-----------|----------------------|------------------------|
| `get_file_list` | Получить список файлов (путь/размер/дата) | `adb shell` | `find` + `stat` |
| `copy_file` | Скопировать один файл | `adb pull` + повторные попытки | `cp` |
| `SOURCE_LABEL` | Подпись в конфликтах | «На телефоне» | «В источнике» |
| `COPY_VERB` | Глагол в сообщениях об ошибках | «скачать» | «скопировать» |
| `SOURCE_MSG` | Для сообщения о неудаче списка | «с телефона» | «из папки» |

# Photos Phone Sync (ADB)

Копирует фото и видео с Android-телефона на ПК через ADB.

## Требования

- Linux с Bash
- Установленный `adb` (`sudo apt install adb` на Debian/Ubuntu)
- Android-телефон с включённой **отладкой по USB**
  (Настройки → Для разработчиков → Отладка по USB)

## Использование

```bash
./src/photos_phone_sync.sh [ОПЦИИ] <папка_на_телефоне> <папка_назначения_на_ПК>
```

### Опции

| Опция             | Описание                                            |
|-------------------|-----------------------------------------------------|
| `-d, --dry-run`   | Режим проверки — без реального копирования          |
| `-v, --verbose`   | Подробный вывод                                     |
| `-s, --skip-all`  | Пропускать все существующие файлы без запроса       |
| `-y, --yes`       | Неинтерактивный режим — «да» на все вопросы          |
| `-l, --logs`      | Сохранять лог в `~/.phone_sync/`                    |
| `-h, --help`      | Показать справку                                    |

### Примеры

```bash
# Копировать все фото из папки камеры телефона
./src/photos_phone_sync.sh /sdcard/DCIM/Camera ~/Pictures

# Сначала предпросмотр — ничего не копируется
./src/photos_phone_sync.sh -d /sdcard/DCIM/Camera ~/Pictures

# Полностью автоматический запуск (без вопросов)
./src/photos_phone_sync.sh -s -y /sdcard/DCIM/Camera ~/Pictures
```

### Как это работает

1. Подключите телефон через USB и подтвердите запрос авторизации на экране телефона.
2. Скрипт ждёт устройство и получает список файлов (имя, размер, дата) одним вызовом `adb shell`.
3. Строится индекс файлов, уже присутствующих на ПК, — поэтому существующие файлы пропускаются мгновенно.
4. Новые файлы скачиваются через `adb pull` в соответствующую папку `YYYY-MM/`.

# Folder Sync (локальная папка)

Копирует файлы из любой локальной папки (например, с подключённого внешнего HDD)
на ПК, сортируя их по папкам месяцев (`YYYY-MM/`) по дате модификации.

## Требования

- Linux с Bash
- `find`, `stat` (GNU coreutils, входят в большинство дистрибутивов)

## Использование

```bash
./src/photos_folders_sync.sh [ОПЦИИ] <исходная_папка> <папка_назначения_на_ПК>
```

### Опции

| Опция             | Описание                                            |
|-------------------|-----------------------------------------------------|
| `-d, --dry-run`   | Режим проверки — без реального копирования          |
| `-v, --verbose`   | Подробный вывод                                     |
| `-s, --skip-all`  | Пропускать все существующие файлы без запроса       |
| `-y, --yes`       | Неинтерактивный режим — «да» на все вопросы          |
| `-l, --logs`      | Сохранять лог в `~/.phone_sync/`                    |
| `-h, --help`      | Показать справку                                    |

### Примеры

```bash
# Копировать все файлы из папки внешнего HDD
./src/photos_folders_sync.sh /media/hdd/DCIM/Camera ~/Pictures

# Сначала предпросмотр — ничего не копируется
./src/photos_folders_sync.sh -d /media/hdd/DCIM/Camera ~/Pictures

# Полностью автоматический запуск (без вопросов)
./src/photos_folders_sync.sh -s -y /media/hdd/DCIM/Camera ~/Pictures
```

### Как это работает

1. Скрипт сканирует исходную папку с помощью `find` + `stat` (имя, размер, дата модификации).
2. Строится индекс файлов, уже присутствующих на ПК, — поэтому существующие файлы пропускаются мгновенно.
3. Новые файлы копируются через `cp` в соответствующую папку `YYYY-MM/`.

## Запуск тестов

Проект включает наборы тестов (юнит- и интеграционные тесты с моком `adb` для скрипта телефона):

```bash
./tests/test_photos_phone_sync.sh
./tests/test_photos_folders_sync.sh
```

Либо запустить все тесты сразу через Makefile:

```bash
make test
```

Ожидаемый вывод: `✅ ВСЕ ТЕСТЫ ПРОЙДЕНЫ` (все тесты пройдены).

## Установка

Устанавливает оба скрипта и общую библиотеку в `/usr/local` (создаются симлинки
`photos-phone-sync` и `photos-folders-sync` в `/usr/local/bin`):

```bash
make install
```

Для установки в пользовательский префикс (например, для локальной установки в домашнюю папку):

```bash
make install PREFIX=~/.local
```

Удаление:

```bash
make uninstall
```
