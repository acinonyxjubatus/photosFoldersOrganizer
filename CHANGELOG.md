# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
У каждого скрипта своя версия: `photos_folders_sync.sh` и `photos_phone_sync.sh`
версионируются независимо, общая библиотека `common.sh` — вместе с ними.

---

## [photos_folders_sync 0.2.0] — 2026-09-17

### Added
- Рекурсивный обход источника: обрабатываются файлы во всех подпапках
  (например, iPhone DCIM со структурой `100APPLE/`…`133APPLE/`), работает
  по умолчанию, без дополнительных флагов. Раскладка по-прежнему плоская —
  `ГГГГ-ММ/`.
- Поддержка путей относительно `src_dir`: `parse_and_index_files` добавляет
  опциональное 4-е поле `relpath` (только для файлов в подпапках; плоские
  списки остаются в старом 3-польном формате — обратная совместимость).
- Сохранение даты модификации при копировании (`cp -p`) — дата съёмки
  не теряется.
- Тесты: рекурсивный обход подпапок (в т.ч. вложенных на 2 уровня),
  сохранение mtime.

### Changed
- `get_local_file_list`: `find` без `-maxdepth 1` — рекурсивное сканирование
  (также в fallback через `stat`).
- Версия поднята с 0.1.0 до 0.2.0; обновлены `show_help` и README.

## [common.sh] — 2026-09-17

### Fixed
- Загрузка библиотеки через симлинк: `SCRIPT_DIR` вычисляется из
  `readlink -f "${BASH_SOURCE[0]}"` — иначе при установке через
  `make install` (симлинки в `/usr/local/bin`) скрипты не находили
  `common.sh` и падали при старте.
- Прогресс-бар: цвет изменён с тёмно-синего (`BLUE`) на светло-голубой
  (`BRIGHT_BLUE`) — тёмно-синий терялся на фиолетовом фоне терминала
  Ubuntu.

### Changed
- `parse_and_index_files`: опциональный аргумент `src_dir` и вычисление
  `relpath` (4-е поле) для файлов в подпапках.
- `sync_files`: чтение 4-го поля и построение пути источника как
  `$src_dir/${relpath:-$filename}`.

## [Makefile] — 2026-09-17

### Fixed
- `common.sh` устанавливается с правами `644` (библиотека, исполняемый
  бит не нужен); скрипты — `755`.
- `ln -sf` → `ln -sfn` (безопаснее при коллизии с директорией).

### Added
- Цели `test-phone` / `test-folders` (запуск тестов по отдельности);
  `test` зависит от обеих.
- Цель `lint` (shellcheck, если установлен).
- `install` зависит от `test` (санитарная проверка перед установкой).

## [0.1.0] — изначальный релиз

### Added
- `photos_phone_sync.sh` — копирование с Android-телефона через ADB
  (`adb pull` с повторными попытками, проверка авторизации устройства).
- `photos_folders_sync.sh` — копирование из локальной папки (плоская
  структура, `find -maxdepth 1`).
- `common.sh` — общие функции: `sync_files()` с параметризацией колбэками,
  прогресс-бар, спиннер, индексация существующих файлов, конфликты,
  dry-run, логирование.
- Тесты для обоих скриптов, Makefile (`test`/`install`/`uninstall`/`clean`).
